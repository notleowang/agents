# Agent Workflows

This directory contains a bunch of agentic workflows that I use in my software development lifecycle.

## Principles

It is now inevitable to not be using AI to boost your productivity, whether that's for work, design, or personal projects. The thing I don't like is that I could vibe-code entire products and apps now, and I think that's bad.

Hence, I hope to adhere to a framework where I can stay mindful of certain principles I want to keep while using agent workflows. 

The key principle for me is that **I want to be able to learn and be the one piloting the entire development process**.

### Disclaimer

These workflows I follow are by no means a standard. Everyone has different ways of utilizing agents in their work, and with AI constantly changing and coming out with new features, I understand that it can be difficult to mold a strict agentic workstyle.

## Folder Structure

Each subfolder in this `workflows/` folder is a self-contained agentic workflow. Every workflow has its own README and a per-tool implementation you can clone
and drop into your project.

Here is a list of workflows I have so far:

- [`spec-driven-dev`](spec-driven-dev/README.md) — team-leader drives a spec, agents implement and validate one task at a time.
- [`pr-review`]() — a panel of agents that give differing perspectives on a pull request review.
